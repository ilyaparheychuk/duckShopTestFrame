## Prerequisites

1. Install all packages from package.json
2. Create .env file
3. Set 3 required variables:

```
   TEST_USER_EMAIL=
   TEST_USERNAME=
   TEST_PASSWORD=
```

## Run tests from command line

All tests:

```
npm run test:all
```

Some test file (see npm scripts in package.json):

```
npm run test:tc1
```
